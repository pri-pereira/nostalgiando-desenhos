# Nostalgiando Desenhos

Bem-vindo ao repositório estático do **Nostalgiando Desenhos**! Este projeto é uma página inicial super nostálgica para clássicos da TV com iframes funcionais do YouTube.

## Como rodar o projeto localmente
1. Dê dois cliques no arquivo `index.html` e ele abrirá no seu navegador.
2. Não precisa instalar nada, o Tailwind CSS é carregado via CDN.

## Como publicar no GitHub Pages
1. Na aba **Settings** (Configurações) deste repositório no GitHub, procure por **Pages** no menu esquerdo.
2. Em **Build and deployment**, selecione **Deploy from a branch**.
3. Em **Branch**, selecione `main` e a pasta `/ (root)`.
4. Clique em **Save**.
5. Aguarde alguns minutos e o GitHub fornecerá o link público do seu site!
